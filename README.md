# DataImportTool

基于 **WinForms + .NET Framework 4.8.1** 开发的 Windows 桌面数据导入工具；
支持从 Excel 批量读取元模型、分类、属性、属性值等业务数据并写入 SQL Server；
内置设置零件匹配规则、领码规则维护能力，提供跨库配置迁移、全属性值追加等全自动 / 半自动化配置管理功能。

## 能干什么

| 功能 | 说明 |
|---|---|
| 分类 / 分类组导入 | 按 Excel 建分类树和分类组，可选"插入分类时同时生成分类表单" |
| 属性 / 属性值导入 | 单条插入、按分类插入、批量导入（物品维度或编号+值两种格式） |
| 批量追加通用属性值 | 给每个分类下的每个属性统一挂一个通用值，只写数据表，不动表单 |
| 超级批量导入 | 一次导分类 + 属性 + 属性值，先预校验再看预览树，导入走事务，失败整体回滚 |
| 元模型属性导入 | 带冲突解决的预览导入 |
| 零件匹配规则配置 | 分类级匹配字段勾选、预保存暂存、默认排除字段 |
| 领码设置 | 合并属性段编辑、编码示例实时预览、跨属性复制分类规则 |
| 配置迁移 | 把工具导入的数据从旧库迁到新库，带迁移前备份、两阶段恢复、序列重设、迁完校验 |
| WFT 脚本处理 | 批量去掉工作流模板里的脚本节点 |

写库的功能都是"预览 → 确认 → 执行"，后台线程跑，带进度条，可以取消。

## 环境

- Windows + Visual Studio 2026（命令行用 MSBuild 17+ 也行）
- .NET Framework 4.8.1，C# 7.3
- 依赖已经放在 `packages/`（EPPlus 4.5.3.3、Newtonsoft.Json 13.0.3），克隆下来直接能编译

## 编译和运行

1. 打开 `DataImportTool.slnx`，生成就行，不用还原 NuGet。
2. 第一次跑先在「数据库连接设置」填服务器、库名、账号密码，存到程序目录的 `config.json`
3. 主界面是功能导航，点卡片或顶部菜单进各功能，每个功能都先预览再执行。

命令行：

```
MSBuild.exe DataImportTool.csproj /t:Rebuild /p:Configuration=Debug /p:Platform=AnyCPU
```

## 源码怎么找

源码都平铺在项目根目录，按功能定位看 [`源码索引.md`](源码索引.md)，里面有每个文件的行数、职责，末尾还有"我要改 X 去哪"速查表。

## 注意

- 工具直接写数据库，**跑之前先备份**。配置迁移自带备份和恢复，但也建议自己再备一份。
- `config_item` 这类配置表是版本链结构（同一个 config_name 好几条记录，靠 version + release_datetime 区分），工具只改最新那条，不修改历史。
- 仅支持Windows服务器和sqlserver数据库；linux、pg和oracle环境暂不支持
